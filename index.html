📚 什麼是力的大小？

⚖️ 力的平衡

當物體兩端受到的力大小相同，物體就不會移動，這種狀態稱為「力的平衡」。

F₁ = F₂  →  物體靜止不動（力的平衡）

➡️ 力不相等時的移動

當兩端的力大小不相同時，物體會往力較大的方向移動，直到兩端力重新達到平衡為止。

F₁ > F₂  →  物體往 F₁ 方向移動

🔺 三個力的合力

三個力同時作用在一個物體上時，我們用合力來描述整體效果。合力是三個力的向量總和。

  • 若合力 = 0，物體不動（力的平衡）
  • 若合力 ≠ 0，物體往合力方向移動
  • 三力均等且角度間隔 120°，合力 = 0 → 平衡
💡 實驗結論整理
情況 結果
兩端力相等（200g = 200g） 迴紋針不動 ✅
兩端力不等（200g ≠ 100g） 迴紋針往 200g 端移動
三力均等且各差 120° 圓環幾乎不動 ✅
三力不等或角度不均 圓環往合力方向移動
🖼️ 示意圖解
🌍 生活中的力平衡

力的平衡在生活中隨處可見！看看下面的例子：

🏋️

拔河比賽

兩隊拉力相等時繩子不動，力大的一方會把繩子拉向自己這側。

🌉

吊橋纜線

橋面由多條纜線均等支撐，合力向上的分力等於橋的重力，維持平衡。

🛍️

雙手提袋

兩手均等分擔重量時感覺最輕鬆；一手較用力時另一手感覺較輕。

🖼️

吊掛畫框

兩條鋼線均等地吊掛畫框，畫框不偏斜；一條較短則畫框傾斜。

🤸

體操平衡木

選手伸展雙臂是為了讓身體重心的合力維持在平衡木上方，保持平衡。

🔩

螺絲起子

多支螺絲固定物件時，每支螺絲受力應盡量相等，物件才不會歪斜。
