📚 什麼是力的大小？

⚖️ 力的平衡

當物體兩端受到的力大小相同，物體就不會移動，這種狀態稱為「力的平衡」。

F₁ = F₂  →  物體靜止不動（力的平衡）

➡️ 力不相等時的移動

當兩端的力大小不相同時，物體會往力較大的方向移動，直到兩端力重新達到平衡為止。

F₁ > F₂  →  物體往 F₁ 方向移動

🔺 三個力的合力

三個力同時作用在一個物體上時，我們用合力來描述整體效果。合力是三個力的向量總和。

  • 若合力 = 0，物體不動（力的平衡）
  • 若合力 ≠ 0，物體往合力方向移動
  • 三力均等且角度間隔 120°，合力 = 0 → 平衡
💡 實驗結論整理
情況 結果
兩端力相等（200g = 200g） 迴紋針不動 ✅
兩端力不等（200g ≠ 100g） 迴紋針往 200g 端移動
三力均等且各差 120° 圓環幾乎不動 ✅
三力不等或角度不均 圓環往合力方向移動
